# ``MetalSprocketsShaderGraph``

Compose Metal shaders at runtime using function stitching.

## Overview

MetalSprocketsShaderGraph lets you build shader graphs in Swift that compile to stitched Metal functions at runtime. This enables dynamic shader composition without writing Metal code.
